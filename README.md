# 我的第一張海報｜Y2K 選物店

畢業製作《這是你想要的世界嗎？》的 Threads 小遊戲。玩家在 7 天內做出第一張店家宣傳海報，每一步可以自己決定或交給 AI，結局頁用「一眼看懂／打中對的人／記得住」三項檢測海報，並連到問卷。

- 正本（文字、數值）：Google 文件「海報遊戲_Y2K_總文件（唯一正本）」
- 遊戲本體：`index.html`（單一頁面，資料在檔案上方的 DATA 區）
- 商品圖：`img/`（Kiki 以 AI 生成）
- 字體：jf open 粉圓 Huninn、Bagel Fat One（SIL OFL 1.1，授權檔在 `fonts/`）；英文標題字 Yink 透過 Adobe Fonts 網頁字型組載入，不放字檔。

每次改版都會在這裡留一筆紀錄，可以回到任何一版。
